# Round 8 — Track Decision + Confidential Compute Evidence Map

## Decision (Dami-authorized)

Round 7 proved the dual-track *combine* path is a structural dead end (0/10, cited). Dami ruled: **can't combine → pick the single better track for us, based on intel.**

**PICK = Confidential Compute Apps (single track).** Grounded in `research/research-brief.md`:
- **~7× fewer dedicated competitors:** ≥44 primary Interoperable repos vs **≥6 primary Confidential** (Competition Density Map).
- **Unowned whitespace (Strategic Whitespace #1, #4):** no current project owns FCC lifecycle operations + proof observability as one product; failure-injection harness is sparse.
- **Named user + verbatim-documented pain** (Community Pain): FCC/Flare builders lose hours to hidden FCC prerequisites, silent indexer hangs, FDC example drift — real GitHub issues. This is the market-reality evidence every prior round lacked.
- **Proven Flare winning shape:** verifiable computation / TEE (2DeFi, Flare Fact Checker, Quince).
- **Builder fit:** Next.js/TS/Solidity matches the CCA competitor stack (AegisFlow).
- Interoperable single-track already produced **0/40** (R5-6) on the native-substitution wall.

## Single-track CCA contract (dual-track requirement DROPPED)

A concept must have a **load-bearing FCC/FCE confidential operation** with ALL of:
1. **Named user with evidenced demand** — a real role that exists today. Strongest: FCC/Flare builders & operators (documented GitHub-issue pain), or a confidential vertical with a named buyer + proprietary workflow.
2. **Naturally-private inputs** — data already confidential (not invented, not already-public-on-chain).
3. **A second party who DEMANDS the proof (the R7 lesson, still binding):** FCC is only load-bearing when someone who controls value must be convinced of a result WITHOUT seeing the private inputs. A single actor computing over their own data and acting = decoration → kill.
4. **Explicit disclosure boundary + machine/attestation status + signed result + on-chain contract verification.**
5. **A real OUTCOME, performed — not just observed.** The confidential operation IS the experience. Pure dashboards/monitors = the "infrastructure that enables vs experiences that do" anti-pattern → kill.
6. **Honest live/simulated boundary** — Coston2 FCC = simulated TEE; real TEE only on Songbird/mainnet. Honest labeling can itself be a product feature.
7. **Solo-buildable, self-contained 90s demo.**

Interoperable Asset primitives (FXRP/FDC/Smart Account) MAY be used as support but need NOT be load-bearing. FDC = 7 fixed attestation types (not an arbitrary hash anchor).

## Confidential opportunity surface (seed — least-saturated first)

From the corpus opportunity map, the confidential clusters ranked by *remaining* whitespace:
- **[PRIMARY WHITESPACE] FCC lifecycle operations, proof observability & recovery (C12):** builders/operators need FCC/FCE, FDC, indexer, attestation workflows to fail visibly and recover — with a real confidential operation + judge-verifiable receipt, not just a monitor. Documented pain, unowned. Anti-pattern guard: it must DO a confidential operation + safe recovery, not merely watch.
- **[PRIMARY WHITESPACE] Cross-primitive integration-test / failure-injection harness (C12):** deterministic failure capsules → confidential policy response → verifiable proof bundle. Sparse.
- **[SECONDARY] Protected work / documents / identity / access (C7):** confidential verification that protects a real asset/human interest (not already-public chain data), with a verifier who acts. Watch collisions.
- **[SECONDARY] Confidential evidence / intelligence / truth-labeling (C10):** private source fusion → signed action code + provenance class. Watch generic-oracle saturation.
- **[GUARDED] Confidential vertical with externally-validated demand (Whitespace #5):** only with a named buyer + proprietary workflow + privacy boundary not replaceable by ordinary encryption.

## Kill triggers (pre-generation design rules)
- **Invented confidentiality / already-public data being "re-hidden"** → kill.
- **Single-actor self-gating (no verifier who demands the proof)** → kill (R7 lesson).
- **Ordinary encryption would do the same** (no genuine TEE/attestation necessity) → kill.
- **Pure observability/dashboard with no performed outcome** → kill (anti-pattern).
- **Saturated confidential surfaces** (see gate-only kill-list, withheld until freeze).
